# RadioNet

Радиоплеер для Android-смартфонов и Android TV. Одно приложение работает на обоих: на телевизоре оно появляется в списке приложений и управляется пультом.

![Иконка](icon-512.png)

## Установка

1. Откройте раздел **[Releases](../../releases/latest)** и скачайте файл `RadioNet-….apk`.
2. На смартфоне откройте скачанный файл и разрешите установку из этого источника.
3. На Android TV скопируйте APK на флешку или отправьте через приложение вроде «Send Files to TV», затем откройте его файловым менеджером.

Новые версии ставятся поверх старых, станции и настройки сохраняются.

## Возможности

- Станции из каталога FMPLAY, при его недоступности — из открытого каталога Radio Browser
- Что сейчас играет и обложки альбомов (каталог FMPLAY)
- Плеер на весь экран по нажатию на значок станции
- Вкладка «Рок · RadioBells»: рок-станции с radiobells.com/rock, приложение само находит их потоки и оставляет только работающие
- Кнопка «Проверить потоки» для любого списка и удаление станций без потока
- Избранное, свои станции по ссылке, поиск и жанры
- Импорт и экспорт станций: txt, m3u, JSON-каталог и база приложения FMPLAY (.db)
- Таймер сна, режим часов, светлая и тёмная тема
- Воспроизведение в фоне с уведомлением (пауза и следующая станция)
- Android TV: навигация пультом, OK — включить и открыть плеер, удержание OK или кнопка «Меню» — меню станции, «Назад» — свернуть, ⏯ ⏭ ⏮ и CH+/CH− — управление

## Как устроено

- `app/src/main/assets/index.html` — весь интерфейс плеера. Этот же файл можно открыть в браузере на компьютере.
- `MainActivity.java` — окно приложения, кнопка «Назад», пульт, выбор файлов, сохранение в «Загрузки».
- `PlaybackService.java` — фоновое воспроизведение и уведомление.

## Сборка

Каждый push в `main` запускает GitHub Actions: собирается подписанный APK и публикуется новый релиз. Локально: `./gradlew assembleRelease` (нужен Android SDK и JDK 17).

### Ключ подписи

Файл `app/release.keystore` (пароль `radionet`) лежит в репозитории, чтобы все сборки подписывались одинаково и обновления вставали поверх. Это удобно для личного использования. Для публикации в магазинах создайте свой ключ, замените файл и задайте пароли через секреты `RADIONET_STORE_PASSWORD`, `RADIONET_KEY_ALIAS`, `RADIONET_KEY_PASSWORD`.
