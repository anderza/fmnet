RadioNet для Windows 10 и 11 (64-бит)

1. Распакуйте архив в любую папку, например в «Документы».
2. Откройте папку RadioNet и запустите RadioNet.exe.
   Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» -> «Выполнить в любом случае».
3. Чтобы запускать с рабочего стола: правой кнопкой по RadioNet.exe -> «Отправить» -> «Рабочий стол (создать ярлык)».

Клавиши: Пробел - старт/пауза, стрелки влево/вправо - станции, F - плеер на весь экран, F11 - окно на весь экран, C - часы.
Станции и настройки хранятся в %APPDATA%\RadioNet.
Не удаляйте и не перемещайте другие файлы из папки RadioNet: они нужны для работы.
